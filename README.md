# ATLAS - Study Graph

## Problem and architecture

ATLAS processes the synthetic STUDY-042 clinical-trial data and answers
auditable questions about subjects, safety, exposure, and disposition. The
implementation is Python-only and uses the CSV files as its source of truth.
`StudyGraph` loads all nine domains (DM, AE, LB, VS, EX, CM, DS, MH, EG),
filters records by cut, applies later corrections, and joins every record by
`USUBJID`. Per-domain indexes make Patient 360 and subject lookups direct
instead of repeatedly scanning the 14,400 laboratory rows.

`src/normalization.py` provides reusable handling for missing values, dates,
numeric values, `<` results, `ND`, decimal commas, and the documented unit
conversion. The query engine reads laboratory reference ranges by test, unit,
and laboratory before applying thresholds.

## Patient 360 and questions

`StudyGraph.patient360(usubjid)` returns the subject's DM record plus all
connected records in the other eight domains. `Atlas.answer(question)` supports
the demonstrated COUNT, LOOKUP, FINDING (including the protocol Hy's Law
screen), and TRAP/wrong-dose questions. Threshold arithmetic and the 14-day
Hy's Law window are implemented in code, not generated by an LLM.

Every factual result includes evidence references in the form
`domain + USUBJID + seq`. References are checked against the graph before they
are returned. If no matching source records exist, ATLAS returns an empty
answer and empty evidence; it does not invent IDs, values, doses, or events.
Unknown wording and unsupported questions also return an empty result.

## Uncertainty and worked example

Results are screening findings, not medical adjudication. Missing, `ND`, or
unparseable values are not treated as positive findings, and a Hy's Law
candidate still requires the protocol conditions and reference ranges to be
met. For example:

```python
from src.study_graph import StudyGraph
from src.atlas import Atlas

graph = StudyGraph("hackathon-data/data")
graph.build(cut=12)
result = Atlas(graph).answer("Find Hy's law candidates")
print(result["answer"])
print(result["evidence"])
```

The evidence list identifies the exact ALT/AST and bilirubin records supporting
each candidate. Run `python testing.py`, `python src/study_graph.py`, and
`python stage1/queries.py` from the repository root to demonstrate the project.
